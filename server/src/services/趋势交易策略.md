## 三、策略执行流程（Pipeline）

### 🔁 Step 1｜收盘初筛（T 日 15:00 后）

**筛选条件（硬性过滤）**：

| 条件 | 规则 |
|---|---|
| 成交量排名 | 当日成交量排名前 **K 名**（默认 K=200） |
| 涨幅 | ≥ N%（默认 N=3%） |
| 非 ST | 剔除 ST / *ST |
| 上市天数 | ≥ 60 日 |

➡ 得到 **初筛股票池 P0**

---

### 🔁 Step 2｜技术面 & 量价打分（P0 → P1）

对 P0 中每只股票计算 **个股基础强度分数 S_base（0–100）**

#### 1. 量价因子（权重 40%）
- 量比 ≥ 1.5
- 放量上涨（量能 > 5日均量 × 1.8）
- 收盘价 > 5 / 10 / 20 均线
- 无长上影线（(high-close)/high ≤ 3%）

#### 2. 趋势因子（权重 30%）
- MACD 金叉或红柱放大
- RSI(6) ∈ [40, 80]
- 股价站在布林带中轨上方

#### 3. 热点因子（权重 30%）
- 所属概念位于当日概念涨幅榜 Top10（+10~30 分）
- 概念内涨停数量 ≥ 3 家（+10 分）

✅ 综合得到 **S_base**

➡ 保留 **S_base ≥ 70** 的股票进入 **P1 备选池**

---

### 🔁 Step 3｜次日竞价加权评分（T+1 日 9:25）

对 P1 中每只股票计算 **最终交易强度 S_final**：

```
S_final = 
    0.5 × S_base
  + 0.3 × 竞价强度
  + 0.2 × 大盘强度分
```

#### 竞价强度计算（0–100）：
- 竞价涨幅 ∈ [1%, 5%]：满分
- 竞价成交量 ≥ 昨日成交量 × 3%：加分
- 高开但无量：减分
- 竞价砸盘（涨幅 < 0）：直接淘汰

#### 具体竞价强度计算策略：

| 维度 | 权重 | 状态 |
|---|---|---|
| 竞价涨幅 | 50 | ✅ 保留 |
| 竞价成交量占比 | 30 | ✅ 保留 |
| 量价匹配修正 | **20 → 30** | ✅ 权重提升 |
| 未匹配盘口 | 10 | ❌ 删除 |

✅ **总分仍为 100 分**

## 五、最终竞价强度公式（伪代码）

```python
def auction_strength(open_pct, auction_vol, prev_vol):
    if open_pct < 0 or open_pct >= 7:
        return 0

    # 1. 涨幅分
    if 1 <= open_pct <= 5:
        s1 = 50
    elif 5 < open_pct < 7:
        s1 = 35
    elif open_pct >= 0.3:
        s1 = 30
    else:
        s1 = 10

    # 2. 成交量分
    r = auction_vol / prev_vol
    if r >= 0.05:
        s2 = 30
    elif r >= 0.03:
        s2 = 25
    elif r >= 0.02:
        s2 = 15
    elif r >= 0.01:
        s2 = 5
    else:
        s2 = 0

    # 3. 量价修正分
    if open_pct > 0 and r >= 0.03:
        s3 = 30
    elif open_pct > 0 and r >= 0.01:
        s3 = 15
    elif open_pct > 0:
        s3 = -30
    elif open_pct == 0 and r >= 0.03:
        s3 = 10
    elif open_pct == 0:
        s3 = -10
    else:
        s3 = -40

    if open_pct < 0 and r < 0.03:
        return 0

    return max(0, s1 + s2 + s3)
```
