# 系统功能与重要逻辑点文档

## 1. 系统概述

本系统是一套面向A股市场的量化选股与信号推送平台，集成了突破信号、放量大涨、市场情绪等多种量化策略，支持历史回测、实时信号生成、自动数据采集与推送。目标是为量化投资者、策略研究者和实盘交易者提供高效、自动化的选股与决策辅助工具。适用于日常选股、策略开发、实盘辅助等场景。

---

## 2. 技术架构

- **前端**：React + TypeScript + Vite + TailwindCSS
  - 主要用于信号展示、策略回测、行情可视化等页面
- **后端**：Node.js + TypeScript + Express
  - 负责数据采集、信号生成、定时任务、API服务
- **数据库**：MongoDB
  - 存储信号、行情、回测结果等结构化数据
- **定时任务**：node-cron
  - 实现自动化数据采集、信号生成、交易日历更新等
- **数据源**：同花顺问财、聚宽、第三方行情接口
- **其他工具**：axios（HTTP请求）、moment（日期处理）、自定义工具库

---

## 3. 数据模型

### 主要数据结构

#### 1. 交易信号（TradingSignal）
- stockCode：股票代码
- stockName：股票名称
- strategy：信号来源策略（如突破、放量大涨等）
- signalDate：信号日期（入场日/Day3）
- day1Date, day2Date：突破日、确认日
- day1/2/3Open/Close/High/Low/Volume/Turnover：各日行情数据
- exitConditions：止盈止损等退出条件
- status：pending/entered/exited
- riskLevel/riskReasons：风险评估
- marketSentimentScore/Advice：市场情绪

#### 2. 交易日历（TradingCalendar）
- tradingDays：所有已知的交易日（YYYYMMDD）
- updatedAt：缓存更新时间

#### 3. 回测结果（BacktestResult）
- stockCode
- buyDate/sellDate
- buyPrice/sellPrice
- profitPercent
- 策略参数等

#### 4. 行情数据（KlineData）
- date
- open/high/low/close
- volume/turnover

## 4. 主要功能模块

### 1. 交易信号生成与推送
- **突破信号**：三日确认法，Day1突破、Day2确认、Day3入场
- **放量大涨**：成交额、涨幅、换手率等多因子筛选
- **信号推送**：自动生成并推送到前端或通知渠道

### 2. 定时任务调度
- **交易日历更新**：每日收盘后自动拉取最新交易日历，支持节假日判断
- **信号生成**：收盘后自动生成次日信号
- **行情采集**：定时采集热股、K线、分时等数据
- **市场情绪分析**：收盘后自动分析市场情绪

### 3. 数据采集与缓存
- **同花顺/聚宽API**：自动采集行情、交易日历、信号候选等
- **本地缓存**：行情、信号、交易日历等均有本地缓存，支持断点续用

### 4. 前端展示与交互
- **信号列表**：按日期、策略、风险等多维度展示
- **回测分析**：支持历史信号回测、收益率统计
- **行情可视化**：K线、分时、涨跌幅等图表
- **参数配置**：支持策略参数、定时任务等自定义

### 5. 重要逻辑点
- **交易日判断**：统一通过交易日历服务，支持节假日和周末
- **信号生成流程**：严格按 Day1/Day2/Day3 逻辑，自动回避非交易日
- **降级容错**：接口异常时自动降级为本地缓存或简单规则
- **数据持久化**：所有关键数据均有本地文件和数据库双重持久化
