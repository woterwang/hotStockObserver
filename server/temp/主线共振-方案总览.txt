## 📐 二、评分模型设计（可落地的量化规则）

### 2.1 评分公式

$$Score_{total} = Score_{量价} + \beta \times Score_{板块共振}$$

其中：
- $Score_{量价}$：现有评分逻辑（0-130分），保持不变
- $Score_{板块共振}$：新增板块评分（0-60分，设上限防止喧宾夺主）
- $\beta$：调节系数，建议起步值 **0.3~0.5**，可通过回测优化

### 2.2 板块共振评分拆解

$Score_{板块共振} = S_{热度} + S_{强度} + S_{地位}$

#### 2.2.1 热度分（风向）—— 0~20分

基于 `/api/market/concepts/hot` 接口返回的排名进行衰减计算：

$$S_{热度} = \min(20, \alpha \times (K - rank + 1))$$

其中：
- $K = 20$（取前20热点）
- $\alpha = 1.0$（衰减系数）
- $rank$：板块在热度榜中的排名

**落地规则表：**

| 热度排名 | 得分 | 说明 |
|----------|------|------|
| Top 1-5 | 15-20 | 核心热点，强共振 |
| Top 6-10 | 10-15 | 次热点，有效共振 |
| Top 11-20 | 5-10 | 边缘热点，弱共振 |
| 20名以外 | 0 | 不计入热度分 |

**重要规则：主概念原则**
- 个股通常归属多个概念，但只取 **Top 1-2 个命中热点的概念** 作为"主概念"计算热度分
- 避免"多概念股"因叠加而虚高
- 主概念选择优先级：热度排名 > 强度值 > 涨停家数

#### 2.2.2 强度分（确认）—— 0~15分

基于 `/api/market/concepts/rank` 接口的 `strength` 值进行验证：

**目的：** 防止"热度高但涨幅差"的概念误导判断

| 条件 | 得分 | 说明 |
|------|------|------|
| 主概念 strength ≥ 80 | +15 | 真强题材 |
| 主概念 strength ≥ 60 | +10 | 较强题材 |
| 主概念 strength ≥ 40 | +5 | 一般强度 |
| 主概念 strength < 40 | 0 | 强度不足，热度分打5折 |

**交叉验证规则：**
- 若热点板块在强度榜中排名靠后（Top30以外），则该板块的热度分 × 0.5
- 若热点板块涨跌幅 `changeRatio` 为负，不计入热度分

#### 2.2.3 地位分（龙头效应）—— 0~25分

基于 `/api/stocks/:code/concepts/detail` 返回的 `leading` 和 `components` 判断：

| 条件 | 得分 | 说明 |
|------|------|------|
| 在主概念的 `leading` 列表中 | +20 | 板块龙头，最具辨识度 |
| 在主概念的 `components` 列表中 | +8 | 核心成分股，有板块光环 |
| 主概念 `limitUpCount ≥ 5` | +5 | 板块效应强，容错率高 |
| 主概念 `riseCount / (riseCount + fallCount) > 70%` | +2 | 板块整体偏强 |

**龙头识别注意事项：**
```typescript
// leading 中的 code 格式可能是 "603601" 或同花顺带市场前缀的格式
// 需要统一转换为6位纯数字代码进行比较
const normalizeCode = (code: string): string => {
  return code.replace(/[^0-9]/g, '').slice(-6);
};

const isLeading = concept.leading.some(l => 
  normalizeCode(l.code) === normalizeCode(stockCode)
);
```

### 4.2 核心服务改造

```typescript
// services/volumeSurgeService.ts 新增方法

import { thsConceptHotRankService, ThsConceptHotItem } from './thsConceptHotRankService';
import { thsStockConceptService } from './thsStockConceptService';
import { conceptRankingService, ConceptRankingItem } from './conceptRankingService';

class VolumeSurgeService {
  // ... 现有代码 ...

  /**
   * 获取板块共振数据（前置准备）
   * 缓存时间：热度榜3分钟，强度榜1天
   */
  private async fetchConceptContext(dateStr: string): Promise<{
    hotConceptMap: Map<string, { rank: number; item: ThsConceptHotItem }>;
    strengthConceptMap: Map<string, ConceptRankingItem>;
  }> {
    // 1. 获取热度榜
    const hotRankResult = await thsConceptHotRankService.fetchConceptHotRank();
    const hotConceptMap = new Map<string, { rank: number; item: ThsConceptHotItem }>();
    hotRankResult.items.slice(0, 20).forEach((item, index) => {
      hotConceptMap.set(item.name, { rank: index + 1, item });
    });

    // 2. 获取强度榜
    const strengthResult = await conceptRankingService.fetchDailyConceptRanking(dateStr, 30);
    const strengthConceptMap = new Map<string, ConceptRankingItem>();
    strengthResult.items.forEach(item => {
      strengthConceptMap.set(item.name, item);
    });

    return { hotConceptMap, strengthConceptMap };
  }

  /**
   * 计算个股的板块共振评分
   */
  private async calculateConceptScore(
    stockCode: string,
    hotConceptMap: Map<string, { rank: number; item: ThsConceptHotItem }>,
    strengthConceptMap: Map<string, ConceptRankingItem>
  ): Promise<ConceptEnhancementResult> {
    const result: ConceptEnhancementResult = {
      hitHotConcepts: [],
      primaryConcept: null,
      isConceptLeader: false,
      leaderInConcepts: [],
      conceptScore: 0,
      conceptScoreDetail: { hotScore: 0, strengthScore: 0, positionScore: 0 },
      conceptLimitUpCount: 0,
    };

    try {
      // 获取个股概念详情
      const conceptDetail = await thsStockConceptService.fetchConcepts(stockCode);
      
      // 遍历个股所属概念，找出命中热点的
      const candidates: Array<{
        name: string;
        hotRank: number;
        strength: number;
        concept: any;
        isLeader: boolean;
      }> = [];

      for (const concept of conceptDetail.concepts) {
        const hotInfo = hotConceptMap.get(concept.name);
        if (!hotInfo) continue; // 不在热度榜中，跳过

        const strengthInfo = strengthConceptMap.get(concept.name);
        const strength = strengthInfo?.strength || 0;

        // 检查是否为龙头
        const normalizedCode = stockCode.replace(/[^0-9]/g, '').slice(-6);
        const isLeader = concept.leading.some(l => 
          l.code.replace(/[^0-9]/g, '').slice(-6) === normalizedCode
        );

        candidates.push({
          name: concept.name,
          hotRank: hotInfo.rank,
          strength,
          concept,
          isLeader,
        });

        result.hitHotConcepts.push(concept.name);
        if (isLeader) {
          result.isConceptLeader = true;
          result.leaderInConcepts.push(concept.name);
        }
      }

      if (candidates.length === 0) {
        return result;
      }

      // 选择主概念：优先龙头所在概念 > 热度排名最高
      candidates.sort((a, b) => {
        if (a.isLeader !== b.isLeader) return a.isLeader ? -1 : 1;
        return a.hotRank - b.hotRank;
      });

      const primary = candidates[0];
      result.primaryConcept = primary.name;
      result.conceptLimitUpCount = primary.concept.limitUpCount || 0;

      // === 计算评分 ===

      // 1. 热度分 (0-20)
      let hotScore = Math.max(0, Math.min(20, 21 - primary.hotRank));
      
      // 若热点板块涨幅为负，热度分归零
      if (primary.concept.changeRatio < 0) {
        hotScore = 0;
      }
      result.conceptScoreDetail.hotScore = hotScore;

      // 2. 强度分 (0-15)
      let strengthScore = 0;
      if (primary.strength >= 80) strengthScore = 15;
      else if (primary.strength >= 60) strengthScore = 10;
      else if (primary.strength >= 40) strengthScore = 5;
      else {
        // 强度不足，热度分打折
        hotScore = Math.floor(hotScore * 0.5);
        result.conceptScoreDetail.hotScore = hotScore;
      }
      result.conceptScoreDetail.strengthScore = strengthScore;

      // 3. 地位分 (0-25)
      let positionScore = 0;
      if (primary.isLeader) positionScore += 20;
      else {
        // 检查是否在成分股中
        const normalizedCode = stockCode.replace(/[^0-9]/g, '').slice(-6);
        const isComponent = primary.concept.components.some(c =>
          c.code.replace(/[^0-9]/g, '').slice(-6) === normalizedCode
        );
        if (isComponent) positionScore += 8;
      }
      if ((primary.concept.limitUpCount || 0) >= 5) positionScore += 5;
      
      const riseRatio = primary.concept.riseCount / 
        (primary.concept.riseCount + primary.concept.fallCount + 0.01);
      if (riseRatio > 0.7) positionScore += 2;
      
      result.conceptScoreDetail.positionScore = positionScore;

      // 总分（设上限60分）
      result.conceptScore = Math.min(60, hotScore + strengthScore + positionScore);

    } catch (error) {
      logger.warn(`获取个股概念失败 ${stockCode}: ${(error as Error).message}`);
    }

    return result;
  }
}
```

const fetchWithTimeout = async <T>(
  promise: Promise<T>,
  timeoutMs: number,
  fallback: T
): Promise<T> => {
  const timeout = new Promise<T>((_, reject) => 
    setTimeout(() => reject(new Error('Timeout')), timeoutMs)
  );
  try {
    return await Promise.race([promise, timeout]);
  } catch {
    return fallback;

本方案通过 **"热度验证 + 强度确认 + 地位加权"** 三层过滤机制，将概念板块数据有机融入现有的量价选股策略，既保留了原有策略的核心优势（量价强势），又增加了市场主线感知能力（板块共振），预期可显著提升选股的准确率和持续性。

- **工程可行性高**：充分考虑了缓存、并发、降级等工程问题
- **可验证可迭代**：提供了完整的回测方案和监控指标
