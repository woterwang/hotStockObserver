# 📈 买入时机量化模型设计文档

## 一、模型概述

### 1.1 策略定位
- **选股阶段**：T日收盘后，通过"强势资金突破"策略筛选标的
- **买入时机**：T+1日开盘（集合竞价9:25 或 开盘9:30）
- **核心目标**：在确认资金延续的前提下，找到最佳介入点位

### 1.2 核心理念
```
好的选股 + 好的时机 = 高胜率 + 高盈亏比
```

选股解决"买什么"的问题，买入时机解决"什么时候买"的问题。

## 二、买入信号评分体系（满分100分）

### 2.1 开盘强度（满分30分）⭐最重要

| 开盘涨幅 | 得分 | 说明 |
|---------|------|------|
| 1% ~ 3% | 30分 | 🌟 最佳区间：强势延续但不追高 |
| 3% ~ 5% | 25分 | 偏高，需注意风险 |
| 5% ~ 7% | 15分 | 追高风险较大 |
| > 7%    | 5分  | ❌ 不建议追高 |
| 0% ~ 1% | 20分 | 资金态度中性，可观察 |
| -2% ~ 0% | 15分 | 可能有低吸机会 |
| < -2%   | 5分  | ❌ 资金不认可 |

**理由**：
- 开盘过高（>5%）意味着追高风险，获利盘抛压大
- 开盘过低（<0%）说明资金不认可，昨日的"强势"可能是假象
- 理想的开盘是1%-3%，既表明资金延续，又留有上涨空间

---

### 2.2 量能确认（满分15分）

| 开盘量比 | 得分 | 说明 |
|---------|------|------|
| ≥ 3     | 15分 | 资金强势涌入 |
| 2 ~ 3   | 12分 | 资金延续良好 |
| 1.5 ~ 2 | 10分 | 有资金关注 |
| 1 ~ 1.5 | 6分  | 关注度一般 |
| < 1     | 2分  | ❌ 资金关注不足 |

**理由**：
- 开盘量比反映资金的延续性
- 量比≥1.5说明资金热情不减，可以介入
- 量比<1说明资金撤退，应该回避

---

### 2.3 竞价抢筹（满分15分）

| 竞价金额占比（相对昨日成交额） | 得分 | 说明 |
|------------------------------|------|------|
| ≥ 5%   | 15分 | 主力大幅抢筹 |
| 3% ~ 5% | 12分 | 有主力抢筹迹象 |
| 2% ~ 3% | 8分  | 正常水平 |
| 1% ~ 2% | 5分  | 一般 |
| < 1%   | 2分  | 竞价冷淡 |

**理由**：
- 集合竞价是主力资金的"投票"
- 竞价金额大说明主力在积极抢筹
- 竞价金额小说明主力观望或已完成布局

---

### 2.4 大盘环境（满分10分）

| 条件 | 得分 | 
|------|------|
| 上证开盘 ≥ 0.5% | +5分 |
| 上证开盘 0% ~ 0.5% | +4分 |
| 上证开盘 -0.5% ~ 0% | +2分 |
| 上证开盘 < -0.5% | +0分 |
| 市场情绪 ≥ 70 | +5分 |
| 市场情绪 50 ~ 70 | +3分 |
| 市场情绪 < 50 | +1分 |

**理由**：
- 大盘是个股的"土壤"，大盘弱势时个股难以独善其身
- 市场情绪（涨停数、跌停数、涨跌比）反映赚钱效应

---

### 2.5 板块联动（满分10分）

| 条件 | 得分 |
|------|------|
| 板块涨停数 ≥ 5 | +5分 |
| 板块涨停数 2 ~ 4 | +3分 |
| 板块涨停数 < 2 | +1分 |
| 是板块领涨股 | +3分 |
| 板块涨幅 ≥ 2% | +2分 |

**理由**：
- 板块效应是短线的核心逻辑
- 有跟风股说明题材有持续性
- 龙头股的溢价最高

---

### 2.6 承接力度（满分10分）- 涨停股专用

| 条件 | 得分 |
|------|------|
| 封单/成交额 ≥ 5 | +6分 |
| 封单/成交额 2 ~ 5 | +4分 |
| 封单/成交额 1 ~ 2 | +2分 |
| 未开板（一字板） | +4分 |
| 仅开板1次 | +3分 |
| 多次开板 | +1分 |

**理由**：
- 封单大说明承接有力，第二天高开概率高
- 开板次数反映分歧程度

---

### 2.7 技术位置（满分10分）

| 条件 | 得分 |
|------|------|
| 距离5日均线 0% ~ 5% | +3分 |
| 距离5日均线 5% ~ 10% | +2分 |
| 距离5日均线 > 10% | +0分 |
| 距离10日均线 0% ~ 8% | +3分 |
| 距离压力位 ≥ 5% | +4分 |
| 距离压力位 2% ~ 5% | +2分 |
| 距离压力位 < 2% | +0分 |

**理由**：
- 均线是支撑，贴近均线风险小
- 压力位是套牢盘，距离压力位越远越好

## 三、买入决策

### 3.1 决策规则

| 总分 | 信号 | 仓位建议 | 操作 |
|------|------|---------|------|
| ≥ 80分 | 🔥 强烈买入 | 3成仓 | 集合竞价直接买入 |
| 60 ~ 79分 | ✅ 建议买入 | 2成仓 | 开盘观察后买入 |
| 40 ~ 59分 | ⏸️ 观望为主 | 1成仓 | 除非有特殊催化剂 |
| < 40分 | ❌ 放弃 | 0仓 | 不介入 |

### 3.2 止损止盈设置

| 类型 | 涨停股 | 非涨停股 |
|------|--------|---------|
| 止损 | -5% | -3% |
| 止盈 | +15% | +8% |

**理由**：
- 涨停股波动大，需要更大的止损空间
- 非涨停股的预期收益较低，止盈目标相应降低

## 四、风险提示系统

自动检测以下风险并发出警告：

| 风险项 | 触发条件 | 提示 |
|--------|---------|------|
| 追高风险 | 开盘涨幅 > 5% | ⚠️ 开盘涨幅过高，追高风险大 |
| 量能不足 | 开盘量比 < 1 | ⚠️ 开盘量能不足，资金关注度下降 |
| 系统风险 | 上证开盘 < -1% | ⚠️ 大盘大幅低开，系统性风险 |
| 情绪低迷 | 市场情绪 < 40 | ⚠️ 市场情绪低迷，谨慎操作 |
| 联动弱 | 板块涨停数 < 2 | ⚠️ 板块联动弱，题材持续性存疑 |
| 超买 | 距离5日均线 > 10% | ⚠️ 短期涨幅较大，注意回调风险 |
| 压力位 | 距离压力位 < 2% | ⚠️ 逼近压力位，套牢盘抛压 |
| 高风险股 | 选股风险等级=高 | ⚠️ 选股风险等级为高，需严格止损 |

## 五、使用方法

### 5.1 API接口

```bash
# 1. 生成买入信号（T+1日开盘前运行）
POST /api/buy-signal/generate
Body: { "date": "20251211" }  # 不传则默认今天

# 2. 获取买入信号列表
GET /api/buy-signal/list?date=20251211&signal=strong_buy

# 3. 获取统计数据
GET /api/buy-signal/stats?date=20251211
```

### 5.2 工作流程

```
T日 15:00后   → 运行选股扫描（强势资金突破）
T日 晚上     → 复盘分析候选标的
T+1日 9:15   → 生成买入信号
T+1日 9:25   → 根据信号决定是否竞价买入
T+1日 9:30   → 或开盘后观察再买入
T+1日 收盘   → 更新收益跟踪
```

## 六、回测验证建议

1. **样本选择**：至少100个交易日的数据
2. **分组对比**：
   - 强烈买入（≥80分）vs 建议买入（60-79分）
   - 不同市场环境下的表现
3. **核心指标**：
   - 胜率（盈利次数/总次数）
   - 盈亏比（平均盈利/平均亏损）
   - 最大回撤
4. **优化方向**：
   - 调整各项评分权重
   - 优化止损止盈参数

---

## 七、模型局限性

1. **数据依赖**：需要实时行情数据，目前部分数据为模拟
2. **市场变化**：A股市场风格多变，模型需要定期优化
3. **黑天鹅**：无法预测突发利空
4. **流动性**：小市值股票可能无法按预期价格成交
