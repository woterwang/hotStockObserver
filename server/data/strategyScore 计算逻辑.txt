strategyScore 计算逻辑
公式

strategyScore = baseScore + marketBonus + boardBonus
               （限制在 0 ~ 130 之间）


一、基础评分 baseScore（0-100分）
维度	条件	得分	说明
1. 涨幅	7% ~ 10%	+20	最佳涨幅
10% ~ 15%	+15	涨幅偏高
> 15%	+10	追高风险增加
2. 换手率	8% ~ 15%	+20	最佳换手
5% ~ 8%	+15	
15% ~ 25%	+12	
> 25%	+5	筹码分散
3. 上影线	≤ 1%	+15	越小越好
≤ 2%	+12	
≤ 3%	+8	
4. 下影线	≤ 1%	+15	越小越好（无抛压）
≤ 2%	+10	
≤ 3%	+5	
5. 振幅	8% ~ 12%	+15	振幅适中，走势健康
< 8%	+12	一字板或接近涨停
≤ 15%	+8	
> 15%	+3	日内震荡剧烈
6. 量比(vs5日)	2x ~ 4x	+15	放量最佳
4x ~ 6x	+12	
> 6x	+8	可能出货
≥ 1.5x	+10	
baseScore 满分 = 20+20+15+15+15+15 = 100分

二、市场环境加分 marketBonus（-20 ~ +15分）
条件	加分	说明
涨停家数 ≥ 100	+10	市场情绪火爆
涨停家数 ≥ 60	+5	情绪较好
涨停家数 < 30	-10	情绪冰点
大盘站上20日均线	+5	趋势向上
大盘跌破20日均线	-10	风险增加
marketBonus 范围 = -20 ~ +15分

三、首板/连板加分 boardBonus（0 ~ +15分）
条件	加分	说明
首板	+15	启动点，最安全
2连板	+10	资金认可
≥3连板	+5	追高风险增加
四、风险等级判定
条件	风险等级
strategyScore ≥ 85 且 大盘站上MA20 且 涨停数 ≥ 60	low（低风险）
strategyScore < 60 或 大盘跌破MA20 或 涨停数 < 30	high（高风险）
其他情况	medium（中等风险）
理论分数范围
情况	分数
理论最低分	0 + (-20) + 0 = -20 → 限制为 0
理论最高分	100 + 15 + 15 = 130
高质量股票门槛	≥ 70分
